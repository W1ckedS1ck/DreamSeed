# Некритичные улучшения DreamSeed

Список идей для усиления проекта под реальный workflow (1 разработчик, MODX, FTP на препрод) и под портфолио DevOps. Сделать когда-нибудь позже.

---

## Топ под реальный workflow

### 1. SFTP с chroot-jail для разработчика (вместо FTP)
Создать роль `sftp_jail`:
- Отдельный пользователь, chroot в `/var/www/html`
- Ключ вместо пароля
- Логи в `/var/log/sftp-audit.log` → Loki/Grafana

Plain FTP — это пароль в открытом виде, в портфолио смотрится плохо. На интервью — сразу плюс: «заменил FTP на SFTP с audit trail».

### 2. Promote preprod → prod одной командой
Скрипт `scripts/promote.sh`:
- `rsync -avz --delete` файлов MODX (исключая `core/cache/`, `core/config/`)
- `mysqldump` preprod → импорт prod (в транзакции + backup до)
- Автоочистка MODX-кэша (`core/cache/*`) + `php core/model/modx/processors/system/clearcache.php`
- Pre/post health-check (curl `/`, проверка HTTP 200 + время ответа)
- Rollback при фейле

Это ровно бизнес-процесс проекта, и именно такое ценят на собеседованиях.

### 3. Auto-deploy hook после FTP/SFTP-загрузки
`inotifywait` (или `lsyncd`) на `/var/www/html` → автоматически:
- Чистит MODX cache
- Прогоняет smoke-тест
- Шлёт в Telegram «deploy OK/FAIL»

Разработчик залил файл — система сама прогнала пайплайн.

## Что сильно усиливает портфолио

### 4. CI/CD (GitHub Actions) — главный минус сейчас
- `tflint`, `tfsec`/`checkov`, `terraform validate`, `terraform plan` на PR
- `ansible-lint`, `yamllint`, `shellcheck` на `deploy.sh` и скриптах
- `gitleaks` — скан секретов
- `molecule` тест хотя бы 2–3 ключевых ролей (nginx, php, mariadb)

### 5. Ansible Vault / SOPS вместо `secrets/.env`
Сейчас `.env` в plain. Перенести на `ansible-vault encrypt` или SOPS+age.
На интервью спросят «как вы храните секреты?» — ответ «в .gitignore» слабый.

### 6. Backup integrity test (killer feature для портфолио)
Раз в неделю по cron:
- Поднимает dev-инстанс
- Заливает последний бэкап через `RESTORE_ALL.sh`
- Проверяет, что MODX отвечает 200
- Рушит инстанс
- Шлёт отчёт в Telegram

Почти никто так не делает — «бэкапы без проверки восстановления это не бэкапы».

### 7. Loki + Promtail для централизованных логов
Access-логи nginx/apache, PHP error, fail2ban, SFTP-audit → Grafana.
Закрывает дыру «only systemd logs on each host».

### 8. Terraform-managed Cloudflare DNS
Cloudflare уже используется для SSL — перенести DNS-записи в `terraform/cloudflare/`.
Убирает ручной шаг и красиво в портфолио.

### 9. Makefile + README с архитектурной диаграммой (Mermaid)
```
make deploy-prod-nginx
make backup
make restore
make lint
```
README на главной с диаграммой `AWS/Hetzner → Terraform → Ansible → MODX → Backup → GDrive` — это первое, что смотрит рекрутер.

### 10. Pre-commit hooks (`.pre-commit-config.yaml`)
- ansible-lint
- tflint
- gitleaks
- shellcheck
- trailing-whitespace

10 минут настройки — большой знак зрелости.

## Приятные бонусы

- **Renovate / Dependabot** — авто-PR на обновления
- **SSL expiry alert** в Grafana (probe cert age < 14d)
- **Dev-refresh из prod-дампа** (анонимизированный) — разработчик тестирует на реальных данных
- **MODX-дашборд в Grafana**: попытки входа в `/manager/`, slow PHP queries, размер cache
- **Cost alerts** через AWS Budgets в Terraform
