# DreamSeed Documentation

Планы, идеи и наработки по улучшению проекта.

## Файлы

- **некритичные_улучшения.md** — Список идей для развития проекта (SFTP-jail, promote workflow, CI/CD, Vault, логирование, etc.)
- **github_ci_план.md** — План внедрения GitHub Actions с линтерами и проверками
- **backup_drill_план.md** — План проведения backup integrity drills
- **promote_feature_notes.md** — Заметки о попытке реализовать promote (dev→prod). Отменено из-за конфликта БД.

## Приоритет

1. Реализовать из "некритичные_улучшения.md" по порядку
2. GitHub Actions (усиливает портфолио)
3. Backup drills (killer feature)
