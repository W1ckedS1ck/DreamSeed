## Методология

Аудит выполнен 6 параллельными агентами по направлениям. **Каждая находка перепроверена вручную** по исходному коду на предмет ложных срабатываний. В таблицы включены только подтверждённые баги.

Обозначения: `✅` — исправлено, `✗` — ложное срабатывание.

## HIGH — 3 находки

| # | Файл | Строка | Описание |
|---|------|--------|----------|
| H3 | `ansible-roles/apache_http/tasks/main.yml` | 89 | **`mod_evasive DOSSystemCommand` без sudoers.** Apache (`www-data`) запускает `sudo /sbin/iptables`. Ни в одном файле нет sudoers-правила для www-data. На Ubuntu 22.04+ `/sbin/iptables` — nftables compat-слой, может отсутствовать. Команда молча фейлится. |
| H4 | `lib/helpers.sh` | 112-123 | **Cloudflare API — ни одна ошибка не проверяется.** Все 4 curl-вызова имеют `>/dev/null 2>&1` или `2>/dev/null` без проверки exit-кода. Функция всегда печатает `✓ Cloudflare DNS:` даже при ошибке. `deploy.sh` не проверяет возвращаемое значение. |
| H7 | `ansible-roles/monitoring/tasks/_install_binary.yml` | 36 | **Нет checksum verification.** `checksum: "{{ monitor_checksum \| default(omit) }}"` — ни один из 7 вызывателей не передаёт `monitor_checksum`. Бинарники (node_exporter, apache_exporter, nginx_exporter, mysqld_exporter, VictoriaMetrics, vmagent) качаются без проверки целостности. |

## Ложные срабатывания (не баги)

| # | Причина |
|---|---------|
| H1 | Архив `smart_backup.sh` использует `basename` от `PROJECT_DIR` (`html/`). `-C /var/www/` сохраняет префикс → файлы в `web_root`. Консистентно по дизайну. |
| H2 | `register` в Ansible сохраняет переменную на хосте, где выполняется таск (remote), а не на delegated. `rclone_config_stat` доступен. |
| H5 | `send_tg()` печатает `WARNING: Telegram send failed (HTTP xxx)` в stderr при ошибке. Обратная связь есть. |
| H6 | `clear_sessions \| default(true)` — намеренно. Очистка сессий при деплое — стандартная практика. |
| H8 | `/var/www/html` — единственный документ-рут MODX в проекте. `check_services.sh` консистентен. |
| H9 | Флаг `/etc/grafana/.admin_password_set` — намеренно. Предотвращает лишний reset пароля на каждом деплое. При смене пароля флаг удаляется вручную. |
| M1 | `ansible.mysql` — корректный FQCN с 2023 года. |
| M4 | AWS `disable_api_termination` и Hetzner `delete_protection` есть. `prevent_destroy` не используется из-за ограничений Terraform 1.11. |
| M5 | SSH check на destroy — чисто косметический лог, не влияет на выполнение. |
| M6 | Egress-правила — намеренная security-харденинг (apt, certbot, rclone). |
| M7 | SM probes только US — осознанно под free tier 10k checks/mo. |
| M8 | Exclude-пути корректны: `PROJECT_DIR` всегда `/var/www/html`. |
| M9 | Heartbeat не срабатывает при lock — `exit 1` до heartbeat. |
| M10 | `php-fpm` — стандартный alias на Ubuntu. |
| M11 | Snapshot всего `/var/www` — намеренно, safety first при restore. |
| M14 | `ENV` env var имеет приоритет. Fallback по hostname корректный для текущих имён. |
| M15 | Entity-парсинг перезаписывает fallback. Команды парсятся правильно. |
| M18 | `-shellcheck=` отключает встроенный shellcheck actionlint — отдельный Job `ShellCheck` покрывает. |
| M19 | `git ls-files` включает staged файлы. |
| M20 | Recidive jail существует в `fail2ban-custom.jail.j2:91-96` (bantime 1 неделя). |
| M21 | `try(jsondecode(file(...)), {...})` корректно фолбечится на заглушку. |
| ~~M22~~ | **✅ ИСПРАВЛЕНО** — `enabledManagers` содержал `"custom.regex"` вместо `"regex"`. Custom managers (Grafana, node_exporter и ещё 10) молча игнорировались. Починено: `"custom.regex"` → `"regex"`, лишний `fileMatch` override удалён. |
