## Приоритетный план исправлений

1. **Renovate `fileMatch`** (C1) — убрать начальный `/` из всех паттернов в `renovate.json`
2. **`prod-hetz` parity** (H1) — в 4 местах заменить `== "prod"` на `=~ ^prod`:
   - `deploy.sh:400` → `target.startswith('prod')` (Python)
   - `deploy.sh:401` → `not target.startswith('prod')` (Python)
   - `deploy.sh:431` → `[[ ! "$TARGET" =~ ^prod ]]` (Bash)
   - `lib/preflight.sh:26` → `[[ "$TARGET" =~ ^prod ]]` (Bash)
3. **Apache `changed_when`** (H2) — строки 110, 117, 125: `'enabled'` → `'Enabling'`, `'disabled'` → `'Disabling'`
4. **Cloudflare API error handling** (H4) — добавить `-f` к curl и проверку HTTP-кода
5. **Мониторинг-бинарники** (H8) — добавить SHA256 checksums в `group_vars/all.yml`
